---------What is an LLM
LLM stands for Large Language Model.
It is an AI model trained on large amounts of text data to understand and generate human-like language.

How does an LLM work?
Imagine you ask:
"Explain Python in simple words."

The LLM:
1. Receives your input.
2. Converts your text into tokens.
3. Processes those tokens using its neural network.
4. Predicts what token should come next.
5. Generates a response token by token.
Important: An LLM doesn't think exactly like a human. It generates responses based on patterns learned during training and the context it receives.


----------What are Tokens?
Tokens are the small pieces of text that an LLM processes.
A token can be:
- A complete word.
- Part of a word.
- A punctuation mark.
- A number or symbol.
For example:
Sentence: I love learning Python.
It might be divided into tokens like:
I
love
learning
Python
.
Why do tokens matter?
1. LLM APIs often charge based on tokens.
2. Models have token limits.
3. Longer prompts consume more tokens.
4. Your input and the model's output both use tokens.
Rule of thumb: In English, 1 token is approximately ¾ of a word, although this varies.


----------Context Window
A context window is the maximum amount of information a model can process in one interaction.
Think of it as the model's working space.

---------For example:
Imagine an LLM has a context window of 8,000 tokens.
You provide:
- System instructions: 500 tokens
- User question: 500 tokens
- Previous conversation: 3,000 tokens
- Retrieved documents: 2,000 tokens
Total = 6,000 tokens.
The remaining capacity is 2,000 tokens, subject to the model's input/output allocation.


--------Inference 
Inference is the process of using a trained AI model to generate predictions or responses.

Simple example:
Training:
- The model learns patterns from training data.
- Its parameters are adjusted.
Inference:
- You give the trained model a prompt.
- It generates an answer.
